# Benchmark task set

The ten task directories are small, reproducible Python optimization fixtures covering algorithm, loops, data structures, string processing, numerical work, allocation, I/O, serialization, concurrency, and caching. Each directory contains `baseline.py`, `tests.py`, `benchmark.py`, and `metadata.json`. They are intentionally modest: the value of the project is in evidence, scheduling, and ablation rather than fabricated speedup numbers.
